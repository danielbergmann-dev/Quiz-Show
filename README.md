# Die letzte Frage

Moderne Fan-Quizshow mit 75 Fragen aus LucasArts-Adventures, Star Wars und Simon the Sorcerer I & II.

15 Gewinnstufen, drei Joker, Themenauswahl, Sound und mobiles Design. Alle Gewinne sind Spielgeld; Publikum und Telefonhilfe sind simuliert.

## Starten

`index.html` im Browser öffnen. Kein Build und keine Installation notwendig.

## GitHub Pages

Im Repository unter **Settings → Pages → Build and deployment** die Option **Deploy from a branch** auswählen. Branch **main**, Ordner **/ (root)** wählen und speichern.

Nach erfolgreicher Veröffentlichung ist die Spieladresse:
https://danielbergmann-dev.github.io/Quiz-Show/

## Dateien

- `index.html`: Einstieg
- `style.css`: Layout und Design
- `app.js`: Spielablauf und Joker
- `questions.js`: Fragenpool

Inoffizielles Fanprojekt, ohne Verbindung zu den Rechteinhabern.
